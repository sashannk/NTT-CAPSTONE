# Nand to Tetris - I (ETCCNT301) Capstone Project

**Personal Number (K):** `05`

## Project Specifications for K = 05
- **Part A (Hardware):** Built `CPU.hdl`, `Memory.hdl`, and `Computer.hdl` and verified against official test scripts (`CPU.tst`, `Memory.tst`, `ComputerAdd.tst`, `ComputerMax.tst`, `ComputerRect.tst`).
- **Part B (Python Assembler):** Two-pass Hack assembler (`assembler.py`) with the assigned `K mod 3 = 2` feature: prints a clear line-numbered warning whenever a duplicate label is declared.
- **Part C (Box Program):** `Box.asm` and `Box.hack` draw a **32 × 20 pixel** black rectangle starting at **Row 5** (`SCREEN + 32 * 5 = 16544`) from the left edge while any key is pressed, and clear it when released.

## Folder Contents
- `CPU.hdl`, `Memory.hdl`, `Computer.hdl` — Hack computer hardware definitions
- `assembler.py` — Two-pass Hack assembler with duplicate-label warning
- `Box.asm` — Hack assembly source for the `32 × 20` box at Row 5
- `Box.hack` — Machine code generated by `assembler.py`
- `DupTest.asm` — Sample test file demonstrating the duplicate-label warning
- `README.md` — Project overview and specifications
